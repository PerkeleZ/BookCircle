# Проверки интерфейса

Скрипты открывают сайт в jsdom (без настоящего браузера), подключают те же скрипты, что и страница, и проходят сценарии за каждую роль:
`smoke.js` — все страницы открываются без ошибок и ошибок JS; `flows.js` — действия (звёзды, окна подтверждения, уведомления, удаление аккаунта, модерация, удаление администратором).

```bash
python manage.py migrate && python manage.py seed --reset
python manage.py runserver 127.0.0.1:8140        # в отдельном терминале
cd tests_ui && npm install && npm test           # BASE_URL=... если адрес другой
```
Сценарии рассчитаны на свежие демоданные (`seed --reset`) и меняют данные: перед повторным запуском выполните `seed --reset`.
jsdom не рисует страницы, поэтому внешний вид (в том числе тёмная тема) нужно смотреть глазами.
