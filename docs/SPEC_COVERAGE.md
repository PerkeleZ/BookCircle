# Соответствие исходному ТЗ («BookCircle — книжный клуб и обмен книгами»)

## Обязательные функции (MVP)
| № | Требование | Реализация |
|---|---|---|
| 1 | Общий каталог: название, автор, жанр, описание, обложка; поиск | `catalog`: `Book`, `/books/?search=&genre=` (регистронезависимо для кириллицы) |
| 2 | Личная полка: экземпляры, состояние, место передачи, доступность | `exchange`: `Copy`, страница «Моя полка» |
| 3 | Запрос с датой возврата; владелец принимает один запрос, остальные отклоняются | `exchange`: `POST /copies/{id}/loans/`, `accept` отклоняет остальные |
| 4 | Отметка передачи и возврата; заёмщик видит срок и историю | `hand-over`, `return`, вкладки «Входящие / Исходящие / На руках» |
| 5 | Личный список чтения со статусами и датой завершения | `reading`: `ReadingEntry`, `/reading/` |
| 6 | Рецензии 1–5 с модерацией; средний рейтинг; счётчик прочитанного за месяц | `reviews`; рейтинг без скрытых; `read_this_month` по `finished_at` |

## Роли, страницы, БД, правила
- **Роли:** участник / модератор / администратор; назначение — только администратором; права на сервере.
- **Страницы:** Каталог, Книга, Моя полка, Обмены, Моё чтение, Модерация; регистрация, вход, профиль, 403/404; ошибки у полей, загрузка, пустые состояния, пагинация, адаптивность.
- **БД:** сущности и ER-диаграмма — [ARCHITECTURE.md](ARCHITECTURE.md); индексы по внешним ключам и фильтрам; уникальности и проверки в БД; история не удаляется каскадом (`PROTECT`).
- **Правила:** одна активная передача на экземпляр обеспечена частичным уникальным индексом и блокировкой; переходы статусов (409 при недопустимых); нельзя запросить свою книгу; переданный экземпляр нельзя скрыть/удалить;
  одна рецензия и одна запись чтения на пару; просрочка вычисляется; скрытые отзывы не входят в рейтинг.
- **Маршруты** (`GET /books`, `POST /copies`, `/copies/{id}/loans`, `/loans/{id}/accept|hand-over|return`, `PUT /reading/{book_id}`, `PUT /books/{id}/review`) реализованы; коды 400/401/403/404/409.

## Критерии приёмки → где проверяются
| Критерий | Проверка |
|---|---|
| Два экземпляра одной книги у разных владельцев бронируются независимо | `exchange.tests.LoanFlowTests.test_two_copies_book_independently` |
| Принять, передать, вернуть; доступность восстанавливается | `test_full_cycle_restores_availability_and_notifies_borrower` |
| Нельзя принять двух заёмщиков | `test_cannot_accept_two_borrowers` (включая ограничение БД) |
| Правка отзыва меняет рейтинг без дубликата | `reviews.tests.test_own_review_can_be_edited_without_duplicates` |
| Запуск по README на чистой базе | `migrate` → `seed` → `runserver` (или `docker compose up`) |
| Основной сценарий через интерфейс, сохранение после перезагрузки | `tests_ui/flows.js` + ручная проверка |
| Права на сервере, ошибки данных, недопустимые переходы | `test_permissions_validation_and_transitions` и тесты прав остальных приложений |

## Демонстрационные данные
`python manage.py seed`: 15 произведений (в том числе жанры «Ужасы» и «Учебники и пособия по IT»), 20 экземпляров, 5 участников, 10 передач, 10 отзывов; плюс модератор и администратор,
одна книга и одна правка на модерации, цели чтения, встречи. Изображений нет (используйте только материалы с разрешённой лицензией).

## Дополнительные функции из ТЗ
Книжные встречи, цели чтения, рекомендации по жанрам — реализованы (`meetings`, `reading`).

аналитика, лендинг, REST-документация, Docker/масштабирование.
